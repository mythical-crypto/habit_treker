# Habit Treker

Habit Treker - приложение для отслеживания привычек. В нем есть регистрация и вход, список привычек, календарь выполнений, статистика и графики.

Этот гайд рассчитан на новичков и показывает, как запустить проект локально по адресу:

```text
http://127.0.0.1:3000/
```

## Что нужно установить заранее

Перед запуском проверьте, что на компьютере установлены:

1. **Node.js 20 или новее**

   Скачать можно с официального сайта: https://nodejs.org/

   Проверка в PowerShell:

   ```powershell
   node -v
   npm -v
   ```

2. **PostgreSQL**

   Скачать можно с официального сайта: https://www.postgresql.org/download/

   Во время установки запомните пароль от пользователя `postgres`. Он понадобится для настройки подключения.

3. **Git** если вы скачиваете проект из репозитория

   Скачать можно с официального сайта: https://git-scm.com/downloads

   Проверка:

   ```powershell
   git --version
   ```

## 1. Откройте папку проекта

Если проект уже лежит на компьютере, откройте PowerShell и перейдите в папку проекта:

```powershell
cd D:\project\habit_treker
```

Если вы только скачиваете проект из GitHub:

```powershell
git clone git@github.com:mythical-crypto/habit_treker.git
cd habit_treker
```

## 2. Установите зависимости

В папке проекта выполните:

```powershell
npm install
```

Эта команда скачает все библиотеки, которые нужны приложению: Next.js, React, Drizzle ORM, Better Auth и остальные зависимости.

## 3. Создайте базу данных PostgreSQL

Приложению нужна отдельная база данных. Самый простой вариант - создать базу с названием `habit_treker`.

### Вариант через psql

Откройте PowerShell и выполните:

```powershell
psql -U postgres
```

Введите пароль от PostgreSQL, который задавали при установке.

Внутри `psql` выполните:

```sql
CREATE DATABASE habit_treker;
```

Затем выйдите:

```sql
\q
```

### Вариант через pgAdmin

1. Откройте pgAdmin.
2. Подключитесь к серверу PostgreSQL.
3. Нажмите правой кнопкой на **Databases**.
4. Выберите **Create -> Database**.
5. В поле имени укажите `habit_treker`.
6. Нажмите **Save**.

## 4. Создайте файл `.env`

В корне проекта создайте файл `.env`.

Путь к файлу должен быть таким:

```text
D:\project\habit_treker\.env
```

Добавьте в него настройки:

```env
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/habit_treker
BETTER_AUTH_SECRET=replace-this-with-a-long-random-secret
BETTER_AUTH_URL=http://127.0.0.1:3000
```

Замените `YOUR_PASSWORD` на пароль от PostgreSQL.

Пример, если пароль от PostgreSQL - `123456`:

```env
DATABASE_URL=postgresql://postgres:123456@localhost:5432/habit_treker
BETTER_AUTH_SECRET=local-development-secret-at-least-32-characters
BETTER_AUTH_URL=http://127.0.0.1:3000
```

Важно: файл должен называться именно `.env`, не `.env.txt`.

## 5. Примените миграции базы данных

Миграции создают таблицы, которые нужны приложению: пользователей, сессии, привычки и отметки выполнений.

Выполните:

```powershell
npx drizzle-kit migrate
```

Если команда прошла без ошибок, база данных готова.

## 6. Запустите приложение на 127.0.0.1:3000

Для разработки используйте команду:

```powershell
npm run dev -- -H 127.0.0.1 -p 3000
```

После запуска в терминале появится сообщение, что сервер работает. Откройте в браузере:

```text
http://127.0.0.1:3000/
```

Если вы не вошли в аккаунт, приложение перенаправит вас на страницу входа.

## 7. Создайте пользователя

При первом запуске база пустая, поэтому нужно создать аккаунт:

1. Откройте `http://127.0.0.1:3000/register`.
2. Введите имя, email и пароль.
3. После регистрации войдите в приложение.

После входа можно создавать привычки и отмечать их выполнение.

## Production-запуск

Если нужно проверить приложение в режиме, близком к production:

```powershell
npm run build
npm start -- -H 127.0.0.1 -p 3000
```

После этого откройте:

```text
http://127.0.0.1:3000/
```

Для обычной разработки удобнее использовать `npm run dev -- -H 127.0.0.1 -p 3000`, потому что он автоматически обновляет страницу после изменений в коде.

## Частые проблемы

### Порт 3000 уже занят

Если при запуске появилась ошибка, что порт `3000` занят, остановите другой сервер.

В PowerShell можно найти процесс:

```powershell
netstat -ano | findstr :3000
```

Затем завершить его по PID:

```powershell
taskkill /PID НОМЕР_PID /F
```

После этого снова запустите приложение:

```powershell
npm run dev -- -H 127.0.0.1 -p 3000
```

### Ошибка подключения к базе данных

Проверьте три вещи:

1. PostgreSQL запущен.
2. База `habit_treker` создана.
3. В `.env` правильно указан `DATABASE_URL`.

Пример корректной строки:

```env
DATABASE_URL=postgresql://postgres:123456@localhost:5432/habit_treker
```

### Файл `.env` не виден

В Windows файл может случайно сохраниться как `.env.txt`.

Чтобы проверить имя файла, выполните:

```powershell
dir -Force
```

В списке должен быть файл `.env`.

### Команда `psql` не найдена

Это значит, что PostgreSQL не добавлен в `PATH`. Можно:

1. Создать базу через pgAdmin.
2. Или открыть **SQL Shell (psql)** из меню Пуск.
3. Или добавить папку `bin` PostgreSQL в переменную среды `PATH`.

Обычно она находится примерно здесь:

```text
C:\Program Files\PostgreSQL\16\bin
```

Номер версии может отличаться.

### После запуска открывается страница входа

Это нормально. Основные страницы приложения доступны только после авторизации.

Создайте пользователя на:

```text
http://127.0.0.1:3000/register
```

Затем войдите через:

```text
http://127.0.0.1:3000/login
```
